> **宿管巡楼提示**：欢迎新租客入住！很多刚接触网络出海的小白租客在拿到机场订阅后不知道如何使用。本篇【入住教程】将为你一步步演示如何在 PC（Windows / macOS）端使用目前最主流、口碑极佳的开源客户端 **Clash Verge Rev**。

---

### 一、 什么是 Clash Verge Rev？

**Clash Verge Rev** 是目前基于 Tauri 开发的下一代 Clash 桌面图形客户端。相较于老旧停更的 Clash for Windows，Verge Rev 具有**占用内存极小**、**界面现代美观**、**原生支持中英双语**以及**内置高效 TUN 模式**等优势，是目前新租客入手的首选客户端。

---

### 二、 准备工作与软件下载

1. **准备材料**：
   - 已购买并激活的机场订阅链接（可在【机场推荐】页面推荐的机场后台一键复制）。
   - 客户端安装包。
2. **下载途径**：
   - 官方 GitHub Release 页面搜索 `Clash Verge Rev`。
   - Windows 用户选择 `.msi` 或 `.exe` 安装包；macOS 用户选择 `.dmg` 安装包（苹果芯片选择 `aarch64`，Intel 芯片选择 `x64`）。

---

### 三、 三步完成一键订阅导入

#### 第一步：复制订阅链接
登录你的机场（如神行加速、大佬云、榴莲云等）后台面板，在【仪表盘】或【一键订阅】区域，点击 **“复制 Clash 订阅链接”**。

#### 第二步：导入到 Clash Verge
1. 打开 Clash Verge Rev 软件。
2. 点击左侧边栏的 **`订阅 (Profiles)`** 选项。
3. 在顶部输入框粘贴你刚才复制的订阅 URL。
4. 点击右侧的 **`导入 (Import)`** 按钮。
5. 等待 2-3 秒，页面显示“成功更新订阅”，并出现对应的机场配置文件卡片。

#### 第三步：选择并启用配置
单击刚刚导入的配置文件卡片，使其边缘亮起勾选图标，表示该订阅配置已成功设为当前生效配置。

---

### 四、 节点选择与运行模式设置

点击左侧边栏的 **`代理 (Proxies)`** 标签页：

1. **选择出海节点**：在节点列表中，点击 **`节点选择 (Proxy)`** 展开组，挑选延迟较低的节点（如香港、日本或新加坡专线节点）。你可以点击右上角的小电波图标，进行批量延迟测速。
2. **选择系统代理模式**：
   - **规则模式 (Rule)**：**强烈推荐**！自动识别国内与国外流量。国内访问（如百度、淘宝）走直连，海外网站（如 Google、YouTube、ChatGPT）走代理。
   - **全局模式 (Global)**：所有网络流量强制走所选代理节点（适合临时测试）。
   - **直连模式 (Direct)**：所有流量不经过代理。

---

### 五、 开启 TUN 虚拟网卡模式（解决 UWP / 游戏 / 终端不走代理问题）

很多新手遇到浏览器能翻墙，但 Telegram 电脑端、Epic/Steam 游戏或命令行不走代理的问题，原因在于普通系统代理无法接管底层的 UDP/TCP 流量。

1. 点击左侧 **`设置 (Settings)`**。
2. 找到 **`TUN 模式 (TUN Mode)`** 开关。
3. 首次开启时，Windows 会弹出管理员权限提示，点击“允许/确认”。
4. 开启后，系统会自动创建虚拟网卡，实现全局无死角接管，游戏与终端均可完美加速。
