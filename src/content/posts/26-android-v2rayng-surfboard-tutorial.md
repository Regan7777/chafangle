> **核心速览 (TL;DR)**  
> 1. **软件定位**：v2rayNG（开源通用型）与 Surfboard（轻量现代型）是 Android 生态主流的代理客户端，本身不提供任何节点。  
> 2. **三步上手**：从 GitHub Releases 或官方渠道下载对应架构安装包（大多选 arm64-v8a） ➔ 在「订阅分组/配置」导入服务商订阅链接 ➔ 选中节点点击连接并允许系统「网络连接 (VPN) 授权」。  
> 3. **避坑重点**：国内手机厂商系统可能会在后台冻结应用，需在系统设置中为客户端关闭「省电策略/电池优化」并开启后台常驻；更新遇 HTTP 429 务必停止连续快速刷新。  

适用于 Android 手机与平板。v2rayNG 和 Surfboard 都是客户端，不包含节点或订阅。本文先让第一次操作的人完成“下载安装—导入—授权—验证”的闭环，再按日志和错误代码判断问题来自订阅、权限、网络还是规则；不要把所有失败都归为“节点坏了”。

## 开始前：准备与下载渠道

准备一条服务商提供的完整订阅链接，并确认手机能通过 Wi-Fi 或蜂窝网络打开普通网页。订阅链接可能包含个人凭据，不能发到群聊、截图公开或粘贴到不可信的在线转换网站。

- v2rayNG：仅从 [项目官方 Releases](https://github.com/2dust/v2rayNG/releases) 下载，与设备架构匹配的 APK。大多数近年 Android 手机选 `arm64-v8a`；不确定架构时先在“设置—关于手机”确认，不要靠反复安装试错。
- Surfboard：查看 [官方安装说明](https://getsurfboard.com/docs/installation/)；安装包和更新渠道以官方页面说明为准。

**正常结果：** 安装完成后能从桌面打开应用，系统没有提示“应用未安装”或“解析包错误”。若安装失败，先确认 APK 是否下载完整、系统版本与架构是否匹配；不要从二次打包网站寻找“修复版”。

## 一、导入订阅：只建立一个可验证的配置

### v2rayNG

1. 打开应用，点击右上角加号；选择“从剪贴板导入”或“订阅分组设置”，取决于链接类型和当前版本界面。
2. 粘贴完整链接，为分组写一个容易识别的名称；保存后只更新这一个分组。
3. 回到首页，确认节点数量和更新时间，再选择一个节点进行测试。

### Surfboard

1. 进入配置或订阅入口，添加服务商提供的订阅链接。
2. 保存后执行一次更新，等列表或配置状态刷新完成。
3. 先保留原有配置，不要在未验证新订阅前删除它。

**正常结果：** 客户端显示配置或节点列表，更新时间接近当前时间。若“更新成功”但节点不变，不要立即转换格式：先确认更新的是正确订阅、对照服务商后台的节点数量，再阅读 [订阅格式与安全转换指南](/posts/37-subscription-format-conversion-guide)。

## 二、首次连接与 Android VPN 权限

1. 在列表中选中一个节点或策略组，再点击连接按钮。
2. Android 第一次会显示 VPN 连接请求；确认发起应用为当前客户端后，点击允许。
3. 连接后，分别打开一个常用国内网站和一个目标网站；不要只以“开关已亮”判断成功。

**正常结果：** 系统状态栏出现钥匙或 VPN 图标，客户端显示运行时间或流量，两个测试能说明规则和网络是否按预期工作。

若按钮提示无法创建 VPN 接口、权限被拒绝，先检查是否有另一款 VPN、工作资料或设备管理策略正在占用 VPN 服务；关闭冲突客户端后再授权。学校或单位发放的受管理设备应先询问管理员，不要通过关闭安全机制解决。

## 三、规则模式、全局代理与网络切换

日常优先使用规则模式：规则决定哪些请求直连、哪些请求使用代理。全局代理只适合临时验证单一目标是否被规则误分流；验证结束后应恢复规则模式。直连模式用于确认本地网络本身是否正常。完整逻辑与检查点见 [直连、规则与全局代理的区别](/posts/39-direct-rule-global-proxy-modes-guide)。

第一次建议在 Wi-Fi 下导入并连接，再切换蜂窝网络复测。若只有校园网、酒店 Wi-Fi 或公司网络失败，先关闭客户端，在浏览器完成网络认证页；确认普通网页能访问后，再连接客户端。蜂窝网络正常而校园网失败，通常是当前网络的限制或认证状态，不是订阅自动失效。进一步步骤见 [网络测速与 DNS 诊断指南](/posts/38-network-speed-dns-diagnostics-guide)。

## 四、按错误代码和日志定位问题

不同客户端与版本的中文提示会不同；以日志里的英文错误、HTTP 状态和发生阶段为准。以下是常见“原始字样—含义—第一步”的对应关系，而不是把所有错误都归为同一种故障。

| 日志或状态 | 更可能的原因 | 先做什么 |
| --- | --- | --- |
| `HTTP 401` 或 `HTTP 403` | 订阅凭据无效、过期或没有权限 | 在服务商后台核对订阅状态；不要反复更新触发限制 |
| `HTTP 404` | 链接已失效或复制不完整 | 重新从后台复制完整链接，不要手写拼接 |
| `HTTP 429` | 请求频率过高 | 停止连续点击更新，稍后只更新一次 |
| `UnknownHostException` | 域名解析失败或当前网络 DNS 异常 | 换 Wi-Fi/蜂窝网络复测，再做 DNS 诊断 |
| `SocketTimeoutException` / `i/o timeout` | 当前网络到订阅或节点的连接超时 | 确认本地网络、测试另一个节点；记录发生时间 |
| `SSLHandshakeException` | 设备时间、证书校验或网络中间页干扰 | 开启自动日期时间；完成校园网认证后再试 |
| `unexpected EOF` / `connection reset` | 连接在传输中被中断 | 固定网络和节点重试一次；仍复现时联系服务商并附最小日志 |
| 返回 HTML 或出现登录页内容 | 校园网认证页、网页拦截页被当成订阅响应 | 先断开客户端并完成网页认证；不要把 HTML 当配置导入 |

不要为消除证书错误而关闭证书验证或照抄陌生“高级参数”。近期 v2rayNG 版本已调整相关弃用选项；应让服务商提供兼容配置，或参考客户端的官方发布说明。

## 五、常见问题（FAQ）

### 导入后显示 0 个节点，日志却没有 HTTP 错误怎么办？

先确认粘贴的不是网页地址、二维码图片地址或已经截断的链接；再核对服务商输出格式是否与当前客户端兼容。只有确认格式不兼容时，才进入 [订阅格式与安全转换指南](/posts/37-subscription-format-conversion-guide)，不要先找第三方转换器。

### 允许 VPN 后连接开关又自动关闭，如何判断是权限还是节点问题？

先查看系统是否同时启用了另一款 VPN、工作资料或管理策略；排除冲突后，以同一节点在同一网络下重试一次。若 VPN 图标出现后才断开，再查看日志中是否有超时、DNS 或 TLS 字样，分别按上表排查。

### `HTTP 429` 更新失败时，能不能不停点击刷新？

不能。429 表示请求被限速；持续刷新只会延长恢复时间。保留完整错误和时间，稍后执行一次更新；若持续出现，向服务商确认订阅限额或后端状态。

### 连上节点后只有校园网无法访问，是否要改 DNS 或换大量节点？

先不要。关闭客户端、完成校园网认证、验证普通网页，再固定一个节点做复测；蜂窝网络正常说明问题更可能是当前网络限制。按 [网络测速与 DNS 诊断指南](/posts/38-network-speed-dns-diagnostics-guide) 判断后再决定是否调整 DNS。

### 切换节点后访问结果完全没变，是不是客户端没有生效？

彻底断开后重新连接，并重开目标 App 或浏览器标签页。长连接、DNS 缓存和登录会话会保留旧结果；确认新的连接记录与节点名称后再判断。
